# FNF Unified Engine — menu prototype

This starter adds an original neon-style menu background and touch zones for Story Mode, Freeplay, Mods, and Settings. The buttons currently show placeholder messages; game modes and mod loading are not implemented yet.

## Files
- `source/Main.hx` — OpenFL menu and touch handling.
- `assets/images/menu_bg.png` — generated menu artwork.
- `project.xml` — OpenFL/Lime project configuration.
- `.github/workflows/android.yml` — Android release APK build.

## Build with GitHub Actions
1. Copy these files into the root of your existing `FNFUnified` repository, preserving the folder structure.
2. Commit and push to `main` (or `master`).
3. Open the repository's **Actions** tab and run **Build Android APK**, or wait for the push-triggered build.
4. Open the successful workflow run, scroll to **Artifacts**, and download `FNF-Unified-APK`.

The generated artwork is a fan-made prototype asset. Before distributing a public game, review the rights and licenses for all recognizable third-party characters, logos, music, and other assets.
